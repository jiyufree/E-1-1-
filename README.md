# 🎯 나만의 퀴즈 게임 (Mission 2)

## 1. 프로젝트 개요
Python 기본 문법과 객체 지향 프로그래밍(클래스)을 활용하여 터미널에서 동작하는 퀴즈 게임입니다. 
JSON 파일을 활용한 데이터 영속성(저장/불러오기)을 지원하여 게임을 종료해도 데이터가 유지됩니다.

## 2. 퀴즈 주제 선정 이유
일반 상식과 대중문화를 주제로 선정하였습니다. 누구나 가볍고 재미있게 풀 수 있으며, 4지 선다형 객관식 포맷에 가장 잘 어울리기 때문입니다.

## 3. 실행 방법
python mission2.py

## 4. 기능 목록
1. **퀴즈 풀기**: 저장된 퀴즈를 4지 선다형으로 풀고 점수를 계산합니다.
2. **퀴즈 추가**: 새로운 문제, 4개의 선택지, 정답을 입력받아 추가합니다.
3. **퀴즈 목록**: 현재 등록된 모든 퀴즈의 질문 목록을 출력합니다.
4. **점수 확인**: 역대 플레이 중 가장 많이 맞춘 최고 점수(정답 수)를 확인합니다.
5. **예외 처리**: 잘못된 입력, Ctrl+C 비정상 종료 시 안전하게 방어하고 데이터를 저장합니다.

## 5. 파일 구조
- `mission2.py`: 퀴즈 게임 메인 실행 코드
- `state.json`: 퀴즈 데이터 및 점수가 저장되는 파일
- `README.md`: 프로젝트 설명 문서

## 6. 데이터 파일 설명 (`state.json`)
- `quizzes`: 개별 퀴즈들의 목록(question, choices, answer 속성 포함)
- `best_score`: 게임을 플레이하며 달성한 최고 정답 개수
